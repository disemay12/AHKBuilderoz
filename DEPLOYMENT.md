# 🚀 Деплой на GitHub Pages

Это пошаговая инструкция по размещению AHK Script Editor на GitHub Pages, чтобы другие люди могли использовать ваше приложение через интернет.

## 📋 Что вам понадобится

- Аккаунт на GitHub ([github.com](https://github.com))
- Git установлен на компьютере
- Ваш проект AHK Script Editor

## 🔧 Пошаговая инструкция

### Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на [github.com](https://github.com) и войдите в аккаунт
2. Нажмите кнопку **"New"** (или перейдите на [github.com/new](https://github.com/new))
3. Заполните форму:
   - **Repository name**: `AHKBuilderoz`
   - **Description**: "Редактор AutoHotkey скриптов с визуальным конструктором макросов"
   - **Public** (обязательно для бесплатного GitHub Pages)
   - ❌ НЕ ставьте галочку "Add a README file" (он уже есть)
   - ❌ НЕ ставьте галочку "Add .gitignore"
   - ❌ НЕ выбирайте лицензию
4. Нажмите **"Create repository"**

### Шаг 2: Загрузите код в репозиторий

Откройте терминал (командную строку) в папке вашего проекта и выполните:

```bash
# Инициализация Git (если ещё не сделано)
git init

# Добавление всех файлов
git add .

# Первый коммит
git commit -m "Initial commit: AHK Script Editor"

# Переименование ветки в main
git branch -M main

# Добавление удалённого репозитория
# Замените YOUR_USERNAME на ваше имя пользователя GitHub
git remote add origin https://github.com/YOUR_USERNAME/AHKBuilderoz.git

# Загрузка кода на GitHub
git push -u origin main
```

### Шаг 3: Настройте GitHub Pages

1. Перейдите на страницу вашего репозитория на GitHub
2. Нажмите вкладку **"Settings"** (Настройки) в правом верхнем углу
3. В левом меню найдите раздел **"Pages"**
4. В разделе **"Build and deployment"**:
   - **Source**: выберите **"GitHub Actions"**
5. GitHub автоматически обнаружит файл `.github/workflows/deploy.yml` и начнёт сборку

### Шаг 4: Дождитесь завершения деплоя

1. Перейдите на вкладку **"Actions"** в вашем репозитории
2. Вы увидите процесс сборки и деплоя
3. Дождитесь появления зелёной галочки ✅ (обычно 1-3 минуты)

### Шаг 5: Откройте ваше приложение

После успешного деплоя ваше приложение будет доступно по адресу:

```
https://YOUR_USERNAME.github.io/AHKBuilderoz/
```

Замените:
- `YOUR_USERNAME` - ваше имя пользователя на GitHub
- `AHKBuilderoz` - имя вашего репозитория

## 🔄 Автоматические обновления

Теперь каждый раз, когда вы делаете `git push` в ветку `main`, GitHub автоматически:
1. Собирает проект
2. Деплоит новую версию на GitHub Pages
3. Обновляет сайт за 1-3 минуты

## 📱 Примеры команд для обновлений

```bash
# После внесения изменений в код
git add .
git commit -m "Добавлена новая функция"
git push

# GitHub автоматически задеплоит изменения!
```

## 🛠️ Решение проблем

### Проблема: Сайт не открывается

**Решение:**
1. Проверьте, что репозиторий **публичный** (Public)
2. Убедитесь, что в Settings → Pages выбран источник "GitHub Actions"
3. Проверьте вкладку Actions - нет ли ошибок сборки

### Проблема: Ошибка 404

**Решение:**
1. Подождите 5-10 минут после первого деплоя
2. Проверьте правильность URL: `https://USERNAME.github.io/REPO_NAME/`
3. Убедитесь, что имя репозитория совпадает с URL

### Проблема: Белый экран или ошибки

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте ошибки JavaScript
3. Убедитесь, что сборка прошла успешно (зелёная галочка в Actions)

2. Настройте автоматический деплой из GitHub
