# 🤖 ИИ-генератор макросов

ИИ-генератор использует **Puter.js** — полностью бесплатный сервис без необходимости регистрации или API ключей.

## 🎯 Возможности

- **Бесплатно**: Никаких платежей, подписок или API ключей
- **Без регистрации**: Просто начните использовать
- **Множество моделей**: GPT-4o Mini, Claude 3 Haiku, Gemini 2.0 Flash, Llama 3.3, DeepSeek V3
- **Понимание русского языка**: Описывайте макросы на русском
- **Автоматическая генерация**: Получайте готовый AHK код за секунды

## 📝 Как использовать

1. **Откройте ИИ-генератор** (иконка ✨ в верхней панели)
2. **Опишите макрос** на русском языке
3. **Выберите модель** (по умолчанию GPT-4o Mini)
4. **Нажмите "Сгенерировать"**
5. **Проверьте результат** и нажмите "Вставить в редактор"

## 💡 Примеры запросов

### Простые макросы
```
Автокликер по F1, 10 кликов с интервалом 100мс
```

### Горячие клавиши
```
При нажатии Ctrl+Alt+T открывать блокнот и писать текущую дату
```

### Поиск элементов
```
Найти красный пиксель на экране и кликнуть по нему
```

### Переключение окон
```
Переключение между окнами Блокнот и Калькулятор по F2
```

### Игровые макросы
```
Макрос для игры: при нажатии F3 быстро нажимать 1, 2, 3 с задержкой 50мс
```

### Работа с программами
```
При нажатии Win+N запускать Notepad++ и вставлять шаблон комментария
```

## 🔧 Технические детали

- **Puter.js**: Библиотека загружается автоматически при первом использовании
- **Интернет**: Требуется для работы (загрузка Puter.js и обращение к API)
- **Лимиты**: Puter.js имеет собственные лимиты использования, но они очень щедрые
- **Приватность**: Puter.js не требует регистрации и не собирает персональные данные

## ⚠️ Возможные проблемы

### "Puter.js не загружен"
- Проверьте интернет-соединение
- Попробуйте обновить страницу
- Убедитесь, что нет блокировщиков скриптов

### "Ошибка генерации"
- Попробуйте другую модель
- Упростите запрос
- Проверьте интернет-соединение

### Медленная генерация
- Нормальное время: 3-10 секунд
- Если дольше — попробуйте другую модель
- Проверьте скорость интернета

## 🎓 Советы

1. **Будьте конкретны**: Чем точнее описание, тем лучше результат
2. **Указывайте горячие клавиши**: Если нужна конкретная комбинация, укажите её
3. **Описывайте поведение**: Что должно происходить при нажатии
4. **Используйте примеры**: Смотрите готовые примеры для вдохновения
5. **Проверяйте код**: Всегда проверяйте сгенерированный код перед использованием
