## ⏭️ Пропущенные задачи

### 1. Темы оформления
**Причина:** Tailwind CSS v4 не поддерживает переопределение классов через CSS-переменные  
**Решение:** Требуется полная переработка компонентов с использованием inline styles или CSS-переменных через arbitrary values

### 2. Интеграция с Git
**Причина:** Требует OAuth авторизацию и backend для безопасного хранения токенов  
**Альтернатива:** Облачная синхронизация через Puter.js

### 3. Плагины и расширения
**Причина:** Очень высокая сложность, требует тщательного проектирования архитектуры  
**Альтернатива:** Встроенные компоненты и галерея макросов

## 🚀 Как использовать

### Локальная разработка
```bash
npm install
npm run dev
```
Открыть http://localhost:3000

### Production сборка
```bash
npm run build
```
Файлы в папке `dist/`

### Деплой на GitHub Pages
1. Запушить код в репозиторий
2. Настроить GitHub Actions (workflow уже создан)
3. Включить GitHub Pages в настройках
4. Сайт будет доступен по адресу: `https://username.github.io/repo-name/`
